# Language version 1 documents (historical)

These files come from the `thecoin` repository (commit `8f620ea`) and describe TCCL language version 1 as shipped with The Coin v0.2.0: the original reference page (`TCCL.md`) and the TCCL Cookbook (`tccl-cookbook.typ`, `tccl-cookbook.pdf`). They are kept unchanged for reference.

The current documentation, covering language versions 1 and 2 in English, Portuguese and Spanish, is in [`docs/en`](../en), [`docs/pt-BR`](../pt-BR) and [`docs/es`](../es), and online at https://tccl.the-coin.cloud.
